# Sicherheitsmeldungen

Bitte melde vermutete Sicherheitslücken vertraulich über
[GitHub Security Advisories](https://github.com/BenediktSchackenberg/Transporter/security/advisories)
mit **Report a vulnerability**. Veröffentliche keine Zugangsdaten, Exploit-Details
oder sensiblen Spielprotokolle in Issues oder Pull Requests.

Nenne nach Möglichkeit den betroffenen Commit oder die Version, Schritte zur
Reproduktion, die Auswirkung und einen möglichen Fix. Sicherheitskorrekturen
werden über die private Meldung koordiniert, bevor Details öffentlich werden.

Unterstützt wird der aktuelle Stand von `main`. Ältere Builds erhalten nicht
automatisch Sicherheitsupdates.

API-Schlüssel gehören nicht ins Repository. Falls ein Schlüssel versehentlich
öffentlich wurde, widerrufe ihn beim Anbieter und erstelle einen neuen. Das
Löschen aus dem aktuellen Dateistand macht einen bereits veröffentlichten
Schlüssel nicht wieder geheim.
